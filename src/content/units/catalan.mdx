<Layer id="intuition">悪い経路を、鏡に映す</Layer>

原点 $(0, 0)$ から点 $(n, n)$ まで、右か上に1マスずつ進む最短経路は ${}_{2n}\mathrm{C}_n$ 本あります。このうち**対角線 $y = x$ より上に一度も出ない**ものは何本でしょうか。

直接数えるのは大変ですが、「上に出てしまう」経路は必ず直線 $y = x + 1$ に触れます。初めて触れた点から先を、この直線に関して折り返してみましょう。

<LatticePath>
  「→ 右」「↑ 上」で経路を作るか、「ランダムな経路」を押してください。朱の経路（悪い経路）は、初めて $y = x + 1$ に触れた点から先を折り返すと、緑の点線のように必ず $(n-1, n+1)$ に到着します。逆に $(n-1, n+1)$ への経路は必ず $y = x + 1$ を通るので、折り返せば悪い経路に戻ります。
</LatticePath>

悪い経路と「$(n-1, n+1)$ への経路」がちょうど1対1に対応するので、悪い経路は ${}_{2n}\mathrm{C}_{n+1}$ 本。全体から引けば答えです。

<Layer id="tool">反射法とカタラン数</Layer>

<Theorem name="対角線を越えない経路の数">

$(0, 0)$ から $(n, n)$ への最短経路のうち、つねに $y \le x$ をみたすものの数は

$$
C_n = {}_{2n}\mathrm{C}_n - {}_{2n}\mathrm{C}_{n+1} = \frac{1}{n+1}\,{}_{2n}\mathrm{C}_n .
$$

$C_n$ を**カタラン数**という：$C_0, C_1, C_2, \dots = 1, 1, 2, 5, 14, 42, 132, \dots$

</Theorem>

2つ目の等号は ${}_{2n}\mathrm{C}_{n+1} = \dfrac{n}{n+1}{}_{2n}\mathrm{C}_n$ から分かります。

カタラン数は「右 = 開き括弧、上 = 閉じ括弧」と読み替えると**正しい括弧列の数**に、「右 = A への投票、上 = B への投票」と読み替えると**開票中つねに A が B 以上である並び方の数**になります。見た目の違う問題が、同じ経路の問題に化けるのです。

<Pitfall title="「越えない」と「触れない」は別の問題">

対角線に触れることも禁止する（端点以外で $y < x$）なら、禁止線は $y = x$ になり、答えも変わります（最初の1歩は右、最後の1歩は上に決まるので、答えは $C_{n-1}$）。問題文の「超えない」「達しない」「下回らない」がどちらの意味かを、図を描いて確かめましょう。

</Pitfall>

<Pitfall title="折り返すのは「初めて触れた点より後」だけ">

経路全体を折り返すと始点も動いてしまいます。最初に禁止線に触れた点を基準にするから、逆向きの操作（$(n-1, n+1)$ への経路を、最初に $y = x + 1$ に触れた点の後で折り返す）がちゃんと元に戻り、対応が1対1になります。

</Pitfall>

<Layer id="why">対応が1対1であることの確認</Layer>

<Proof>

悪い経路（$y = x + 1$ に触れる経路）全体を $\mathcal B$、$(0, 0)$ から $(n-1, n+1)$ への最短経路全体を $\mathcal D$ とする。

**$\mathcal B \to \mathcal D$**：$P \in \mathcal B$ が初めて $y = x + 1$ に触れる点を $T$ とし、$T$ より後の各歩の「右」と「上」を入れ替える。$T$ から $(n, n)$ までは右 $a$ 歩・上 $b$ 歩で、$T = (t, t+1)$ より $a = n - t,\ b = n - t - 1$。入れ替えると右 $b$・上 $a$ 歩になり、終点は $(t + b, t + 1 + a) = (n-1, n+1)$。

**$\mathcal D \to \mathcal B$**：$Q \in \mathcal D$ は始点で $y - x = 0$、終点で $y - x = 2$ なので、1歩ごとに $y - x$ が $1$ ずつ変わることから、途中で必ず $y - x = 1$ になる。初めてそうなる点の後を同様に入れ替えると $(n, n)$ に着き、$y = x + 1$ に触れているので $\mathcal B$ に属する。

2つの操作は「初めて触れる点」を変えない（その点より前は変えていない）ので、互いに逆の操作である。よって $|\mathcal B| = |\mathcal D| = {}_{2n}\mathrm{C}_{n+1}$。

</Proof>

この証明には高校範囲外の道具は1つも使われていません。範囲外なのは「**この対応を思いつくこと**」で、それこそが反射法という技法の中身です。

<Layer id="exam">答案ではどう扱うか</Layer>

> $(0, 0)$ から $(5, 5)$ まで最短経路で進むとき、つねに $y \le x$ をみたす経路は何通りあるか。

<Craft kind="idea">

$C_5 = \dfrac{1}{6}\,{}_{10}\mathrm{C}_5 = \dfrac{252}{6} = 42$。答えを知っていれば、どの解法で解いても検算できます。

</Craft>

<Craft kind="direct">

「カタラン数の公式より 42」だけでは、根拠を示したことになりません。公式を使うなら、第3層のような対応の説明（どの点で、何に関して折り返すか、なぜ1対1か）を書く必要があります。反射法の説明自体は範囲内の議論なので、丁寧に書けば答案として成立します。

</Craft>

<Craft kind="rebuild">

**解答例（書き込み方式）．** 各格子点 $(x, y)$（$y \le x$）に、そこへ至る経路の数を書き込む。$y = 0$ の点はすべて $1$、それ以外は「左の点の数 + 下の点の数」（$y > x$ の点は $0$ とみなす）。

| $y \backslash x$ | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 5 | | | | | | **42** |
| 4 | | | | | 14 | 42 |
| 3 | | | | 5 | 14 | 28 |
| 2 | | | 2 | 5 | 9 | 14 |
| 1 | | 1 | 2 | 3 | 4 | 5 |
| 0 | 1 | 1 | 1 | 1 | 1 | 1 |

答え：42 通り

</Craft>

書き込み方式は確実ですが、$n$ が大きいと手間がかかります。$n$ が文字のまま問われたら、反射法の説明を答案に書きましょう。

<Layer id="advanced">包除原理</Layer>

「少なくとも1つの条件をみたすもの」を数えるときは、重なりを足し引きして調整します。集合 $A_1, \dots, A_n$ について

$$
|A_1 \cup \cdots \cup A_n| = \sum_i |A_i| - \sum_{i<j}|A_i \cap A_j| + \sum_{i<j<k}|A_i \cap A_j \cap A_k| - \cdots + (-1)^{n-1}|A_1 \cap \cdots \cap A_n|.
$$

$n = 2, 3$ の場合は高校でも学ぶ式で、これはその一般形です。典型例は**完全順列**（どの $i$ も $i$ 番目に来ない並べ方）の数：$i$ 番目に $i$ が来る並べ方の集合を $A_i$ とすると、$k$ 個の共通部分の大きさは $(n-k)!$ なので

$$
!n = n! - {}_n\mathrm{C}_1(n-1)! + {}_n\mathrm{C}_2(n-2)! - \cdots = n!\sum_{k=0}^{n}\frac{(-1)^k}{k!}.
$$

$n$ が大きいと $!n / n!$ は $\dfrac1e$ に近づきます（単元1の $e^x$ の展開で $x = -1$）。

<Exercise id="cat-1" n={1} title="対角線を越えない経路" level="基本">

$(0, 0)$ から $(6, 6)$ への最短経路のうち、つねに $y \le x$ をみたすものの数を、反射法で求めよ。

<Step kind="answer">

全体 ${}_{12}\mathrm{C}_6 = 924$、悪い経路は $(5, 7)$ への経路と1対1に対応して ${}_{12}\mathrm{C}_7 = 792$。

答え：$924 - 792 = 132$（$= C_6$）

</Step>

</Exercise>

<Exercise id="cat-2" n={2} title="正しい括弧の並べ方" level="標準">

開き括弧「(」4個と閉じ括弧「)」4個を1列に並べるとき、括弧の対応が正しくとれる（左から読んでいく途中で「)」の個数が「(」の個数を超えない）並べ方は何通りか。

<Step kind="hint" n={1}>
「(」を右へ1歩、「)」を上へ1歩とすると、条件は「つねに $y \le x$」です。
</Step>

<Step kind="answer">

$(0, 0)$ から $(4, 4)$ への経路でつねに $y \le x$ をみたすものと1対1に対応するので、$C_4 = {}_8\mathrm{C}_4 - {}_8\mathrm{C}_5 = 70 - 56 = 14$。

答え：14 通り

</Step>

</Exercise>

<Exercise id="cat-3" n={3} title="開票の途中経過" level="標準">

A に5票、B に3票が入った。1票ずつ開票するとき、開票の途中で常に A の票数が B の票数以上である開票順（票の並び）は何通りか。ただし同じ候補の票は区別しない。

<Step kind="hint" n={1}>
$(0, 0)$ から $(5, 3)$ への経路で、つねに $y \le x$ をみたすもの。悪い経路の終点を $y = x + 1$ に関して折り返すと、$(5, 3) \to (2, 6)$ です。
</Step>

<Step kind="answer">

全体 ${}_8\mathrm{C}_3 = 56$。$y = x + 1$ に触れる経路は、初めて触れた点より後を折り返すと $(2, 6)$ への経路と1対1に対応し、${}_8\mathrm{C}_2 = 28$ 通り。

答え：$56 - 28 = 28$ 通り

</Step>

</Exercise>

<Exercise id="cat-4" n={4} title="誰も自分の席に座らない" level="発展">

5人がそれぞれ自分の席を持っている。5人が5つの席に1人ずつ座るとき、誰も自分の席に座らない座り方は何通りか。包除原理を用いて求めよ。

<Step kind="hint" n={1}>
人 $i$ が自分の席に座る座り方の集合を $A_i$ とし、$|A_1 \cup \cdots \cup A_5|$ を求めて全体から引きます。
</Step>

<Step kind="answer">

$k$ 人が指定されて自分の席に座る座り方は $(5 - k)!$ 通りなので

$$
|A_1 \cup \cdots \cup A_5| = 5\cdot4! - 10\cdot3! + 10\cdot2! - 5\cdot1! + 1\cdot0! = 120 - 60 + 20 - 5 + 1 = 76 .
$$

答え：$120 - 76 = 44$ 通り

</Step>

</Exercise>
